# Approved visual reference

These are archived design/implementation captures, not a live view or a guarantee
that every later control appears in the mockup. Current behavior and deployment
are described in [browser controls](../../WEB_UI.md) and
[current status](../../WEB_UI_MIGRATION_STATUS.md).

`approved-minimal.html` is the preserved minimal mockup the user approved.
`approved-minimal.png` is its existing reference capture. The original files were
copied from the local mockup workspace, without changing their content.

Open the HTML file in a browser to explore it. Its controls are simulated; it
does not connect to a game. Preserve this reference while implementing the real
interface. Hidden explanatory/demo content in its source is not a requirement
for the finished product. Follow the visible minimal layout and the migration
plan's accessibility, calibration, and error-message requirements.

The approved capture records the original desktop target. `implemented-dashboard.jpg`
and `implemented-settings-mobile.jpg` record the actual browser implementation
using disposable fake-device data. Desktop and phone-size browser checks passed
for that capture. Subsequent Ubuntu/LAN, CasaOS, and game-action checks are recorded
separately in the current status; these images contain no live game data.
