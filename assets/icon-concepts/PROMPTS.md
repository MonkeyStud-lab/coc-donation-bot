## Elixir emblem — elixir-emblem.png

Use case: logo-brand. Asset type: original CasaOS dashboard app icon for a community game assistant called CoC Bot. Create one polished square app icon with a bold violet elixir droplet as the single central emblem. Inside the droplet, use a subtle negative-space castle battlement shape to connect the resource and village ideas. Style: sophisticated, restrained dimensional enamel, simple silhouette, matte deep navy rounded-square tile with a clean fine rim. Use the game's implied violet resource and gold-metal accents sparingly. No robot face. No text, initials, numbers, watermark, existing game logo or copied franchise artwork. Strong legibility at 64 pixels, generous safe padding around the emblem, centered, straight-on, crisp edges, no busy scene, no scattered decorations. Finished icon itself, not a sheet or device mockup.
